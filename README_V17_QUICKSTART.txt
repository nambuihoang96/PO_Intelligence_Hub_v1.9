PO INTELLIGENCE HUB v1.7 - UNIFIED RESEARCH STUDIO (MVP)

Windows quick start:
1) Extract ZIP to a folder.
2) Run RUN_WINDOWS.bat (Python 3.10+ required).
3) Click "Research Studio v1.7" in the sidebar, or open http://127.0.0.1:8765/studio.html
4) Create a Research Project: question, market (Utilities / Games), GEO, public keywords.
5) Choose Public Only or Public + Imported CSV. Import CSV is OPTIONAL.
6) Check Market Overview. Quick Snapshot is deterministic data, not an AI insight.
7) Run Public Discovery and/or import Sensor Tower CSV; check evidence coverage and errors.
8) Prepare AI Market Analysis. Copy packet to ChatGPT (Manual) and import real JSON, or use confirmed Codex Auto if installed and enabled.
9) Review market insights and evidence; send selected research actions to v1.5 Action Registry; export report.

IMPORTANT:
- No bundled Sensor Tower CSV, no hard-coded market trends.
- Existing v1.5 workflows remain accessible from the main sidebar.
- Local data lives in data/research.sqlite3; back up before upgrades.
- The original v1.6.1 CSV Lab remains available as a legacy standalone tool.
- Public listings do NOT prove downloads or scale; one CSV period does NOT make a daily timeline.
