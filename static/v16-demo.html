Local CSV Analysis

1. Import Sensor Tower CSV

Chọn một hoặc nhiều file CSV xuất từ Sensor Tower. Có thể import file Downloads PoP, Downloads YoY hoặc cả hai. Dữ liệu sẽ được ghép theo Unified ID + platform + GEO + kỳ báo cáo.

Hỗ trợ UTF-16 TSV (định dạng CSV Sensor Tower) và UTF-8 CSV.
Không có CSV vẫn dùng được các tính năng public research trong Hub chính. Workspace này chỉ phân tích file bạn chủ động import; không tự nạp dữ liệu từ những lần trò chuyện trước.

Data validation
